# みんなカード (Minna Cards)

A lightweight flashcard and quiz app for learning Japanese vocabulary
following the **みんなの日本語** (Minna no Nihongo) chapter structure.

Live app: https://arturosbr.github.io/minna-cards/

---

## What is this?

Minna Cards is a simple web app made to practice vocabulary chapter by
chapter.

It is built to be a no cookies, no log in, no downloads, no bullshit tool:
open the link and start studying right away without accounts, trackers, or
installs.

## Features

- **Study mode**: Browse vocabulary by chapter with kana, kanji, and English.
- **Quiz mode**: Practice English -> Kana or Kana -> English.
- **Configurable sessions**: Select chapters and set how many words to quiz.
- **Missed word review**: Automatically re-tests words answered incorrectly.
